# Car Sales Dashboard
This project features an interactive car sales dashboard created using Power BI. It helps analyze key performance indicators and identify sales trends.
# Project Description
The project includes data visualization for sales, allowing you to track total revenue, sales volume, and average price.The first page covers overall sales metrics, including analysis by region, body style, and monthly trends. The second page focuses on detailed analytics by model, transmission type, and average vehicle price across different companies.
# Key Features
Overall Metrics: Displays total sales volume, quantity of cars sold, and average price.
Body Style and Regional Analysis: A donut chart showing sales by body style and a bar chart by region on the first page.
Trends and Companies: A line graph tracking monthly sales trends and an analysis of sales by manufacturer.
Detailed Analytics: Information on sales broken down by models and transmission types on the second page.
Pricing: Average price by company and a chart of the top 10 most expensive models.
Tools
Power BI Desktop: The primary tool for developing the data model and creating visualizations.
